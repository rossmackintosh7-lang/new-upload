Publishing

Publish only when the site is ready.

PBI lets you build first. Payment is required when you choose to make the website live.

1

Save the project

Use the builder save button so your latest wording, images, pages and settings are stored against your account.

2

Run readiness checks

Check for a hero section, contact route, SEO title, SEO description, mobile layout and package limits.

3

Complete checkout

Choose the package and complete Stripe checkout. No payment is taken while you are only building or previewing.

4

Go live

After payment, publish from the payment page or dashboard. PBI stores the live slug and marks the project as published.
