Stripe setup

Connect payments before accepting real orders.

Stripe checkout and retail tools need real Stripe secrets and price IDs in Cloudflare before they can take live payments.

Required secrets

Add `STRIPE_SECRET_KEY` as a Cloudflare secret. Keep it out of public files and GitHub.

Required prices

Confirm the Starter, Business, Plus and add-on price IDs in Cloudflare variables match the live Stripe account.

Test first

Run a checkout with a test project, return to the payment page and confirm the project billing status updates.
